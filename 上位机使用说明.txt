================================================================
Mini Keyboard 上位机工具使用说明 (host_cli.py)
================================================================

上位机就是工程根目录的 host_cli.py，一个纯 Python + pyserial
的命令行小工具，通过 USB CDC 虚拟串口与键盘固件通信，
目前支持两条命令：同步系统时间、设置 LED RGB 主题色。

------------------------------------------------------------
一、前置条件
------------------------------------------------------------
1. 键盘用 USB 线连接电脑（走的是 USB CDC 虚拟串口，不是 BLE）；
2. 键盘模式开关拨到 USB 档；
3. 固件里已启用 host CDC 通道（当前固件已带此功能）；
4. 电脑装有 Python 3 和 pyserial：
       pip install pyserial

------------------------------------------------------------
二、常用命令（在工程根目录运行）
------------------------------------------------------------

1) 先扫描，找到键盘在哪个 COM 口：
       python host_cli.py scan
   设备管理器里能看到两个新 COM 口，扫到后会提示类似：
       [+] 找到 1 个设备: COM13

2) 同步电脑时间到键盘（LCD 时钟对时）：
       python host_cli.py COM13 time
   默认按 UTC+8 处理。换时区用 --tz：
       python host_cli.py COM13 time --tz 480     (UTC+8，中国默认)
       python host_cli.py COM13 time --tz 0       (UTC)
       python host_cli.py COM13 time --tz -300    (UTC-5)

3) 设置 LED RGB 主题色：
       python host_cli.py COM13 rgb 255 0 0        (纯红)
       python host_cli.py COM13 rgb 76 158 245     (任意 R G B，0-255)

调试时可加 --debug，会打印收发原始帧字节，方便排查协议问题。

------------------------------------------------------------
三、常见提示的含义
------------------------------------------------------------
1. "未找到设备"
     键盘没插 / 开关不在 USB 档 / COM 口被其它程序占用。

2. "未收到 HelloRsp 响应"
     串口能打开但固件没回应，多半是端口选错（不是键盘的 CDC 口），
     或固件版本不对。

3. "时间同步失败: INVALID_PARAM"
     当前键盘里刷的还是旧版固件（含 UTC 毫秒截断 bug），
     需要先重新刷入最新编译的固件才能成功。

------------------------------------------------------------
五、刷机固件产物位置（已核实）
------------------------------------------------------------
build.bat 默认构建，输出产物：
      build/merged.hex        <- 用于下载/烧录
      build/kb/zephyr/zephyr.hex
注：build2/merged.hex 与 build/merged.hex 内容一致（已用
SHA256 校验），两者均可用于烧录。烧录后重新插拔 USB
（或复位键盘），再用 host_cli.py COMx time 验证。

------------------------------------------------------------
四、协议说明（给固件开发者参考）
------------------------------------------------------------
帧格式：55 AA <len> <payload>，payload 最大 64 字节，
为 protobuf 变长编码的 DeviceMessage 子集。
固件端对应实现：src/usb/usb_host_cdc.c
主机端构造：host_cli.py 中 pb_* / encode_* 函数。

能力标志(caps)：bit1 = 时间同步(TimeSync)，bit2 = RGB 主题色(ThemeRgb)。
当前固件上报 caps = 0x06。
