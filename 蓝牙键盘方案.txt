蓝牙小键盘 BLE + USB 双模实现方案与验证方案
================================================

版本：V0.1
适用范围：基于 nRF52840 + Zephyr + CAF 的 17 键数字小键盘
原理图：SCH_蓝牙小键盘_2026-03-28.pdf
说明：本文件只描述实现思路、模块划分与验证方法，不包含代码。

------------------------------------------------
一、结论摘要
------------------------------------------------
1. 以 nRF52840 无线模块 U36（E73-2G4M08S1C）作为唯一主控，USB 与 BLE 共用
   同一套键盘事件源和 HID 按键映射，通过模式状态机决定当前输出通道。
2. 键盘采用 6 行 x 4 列矩阵扫描，17 个机械按键，每个按键配套 1 颗 WS2812B
   RGB LED，实现按下点亮、松开渐灭，颜色可由上位机下发。
3. EC11 旋钮编码器实现音量加减与静音切换。
4. SPI 屏 + LVGL 显示当前模式、系统时间、屏幕亮度和电池电量。
5. 使用 IP5306-I2C 电源管理芯片 + 3.3V LDO + 电池 ADC，实现充放电检测、
   电量计算和低功耗状态管理。
6. 通过 BLE 自定义 GATT 服务与 USB HID Vendor 报告，实现系统时间同步和
   LED 颜色/亮度/效果设置。
7. 采用 Zephyr 输入子系统、设备树和 CAF 事件驱动架构，避免直接写死 GPIO，
   便于调试、移植和后续扩展。

------------------------------------------------
二、硬件资源梳理（依据原理图）
------------------------------------------------

2.1 主控与调试
- U36：E73-2G4M08S1C，nRF52840 无线模块。
- 外部低速晶振 X1：32.768 kHz。
- SWD/SWC：程序下载与调试。
- USB DP/DN：USB 2.0 全速 HID。

2.2 USB 接口
- CN1/USB1：TYPE-C 16 脚接口。
- CC1/CC2 配置下拉电阻，使主机识别为 USB 设备。
- U39（USBLC6-2SC6）：DP/DN ESD 保护。
- R23/R24：DP/DN 串联 0R，便于调试时断开或匹配。
- VBUS 检测用于 USB 插入唤醒和模式切换依据。

2.3 键盘矩阵与按键灯
- 矩阵信号：ROW0-ROW5、COL0-COL3。
- 按键数量：17 个，对应数字小键盘布局。
- 每个按键子模块（CBB1-CBB17）包含：
  - 机械按键 + 热插拔轴座；
  - 1N4148W 防鬼键二极管；
  - 1 颗 WS2812B-MINI-V3J 可寻址 RGB LED。
- RGB 灯通过 DIN/DOUT 级联，RGB_DATA / RGB_1-RGB_4 组成灯带通道，
  具体通道数以最终网表为准，在设备树中配置 GPIO 与 LED 数量。
- RGB_PWR_EN 控制 RGB_VCC_OUT 供电开关，用于低功耗时切断灯带电源。

2.4 旋钮编码器
- SW3：EC11E15244G1。
- EC11A/EC11B：旋转 A/B 相信号，接入 GPIO 或 QDEC。
- 编码器按键：按原理图接入矩阵或独立 GPIO，软件需将其映射为静音按键；
  最终按键通路以网表为准。

2.5 屏幕
- P3：2.54mm 1x8P 屏幕接口。
- 信号：SCREEN_BLK、SCREEN_RES、SCREEN_DC、SCREEN_SDA、SCREEN_SCL、
  SCREEN_CS、3V3、GND。
- 接口性质：SPI 4 线，SDA 为 MOSI，SCL 为 SCLK，DC 为数据/命令选择，
  RES 为复位，BLK 为背光 PWM。
- 推荐按 ST7789V/ILI9341 等 SPI LCD 配置，实际驱动 IC 以屏幕规格书为准。

2.6 电源与电池管理
- U2：IP5306-I2C，负责充电、升压、电池保护和电量指示，带 I2C 接口。
  - IP5305T_I2C_SCK / IP5305T_I2C_SDA：I2C 通信。
  - KEY：电源按键。
  - BAT：电池电压检测相关。
  - LED1-LED3：电量指示。
  - VIN/VOUT/SW/EP：充电输入、升压输出与功率级。
- U37：TPSPX3819M5-L-3-3，3.3V LDO，为 MCU 和数字外设供电。
- U40：1uH 电感，配合 IP5306 升压电路。
- SW4：SK-22D02-G040，系统电源开关。
- H1/CN1：3 脚电池接口，包含 VBAT、BAT_ADC、GND。
- BAT_ADC_EN / BAT_ADC：电池电压采样控制与 ADC 输入。
- MANUAL_WAKE / IP5305T_WAKEUP：手动唤醒与 PMIC 唤醒。
- U41：SN74LVC1G123DCTR 单稳态电路，用于电源按键/唤醒时序整形。
- SYS_POWER / VBAT / LDO_3V3 / 3V3：系统主电源网络。

2.7 模式选择
- U1：SK-13D07-4 开关，输出 MODE 信号，用于选择 USB/BLE 工作模式。
- 软件读取 MODE 电平或边沿变化，切换活动输出通道。

------------------------------------------------
三、总体软件架构
------------------------------------------------

3.1 基础平台
- 推荐使用 Nordic nRF Connect SDK（NCS）2.6 或更高版本，内部包含 Zephyr
  RTOS、Zephyr 蓝牙协议栈和 Zephyr USB 协议栈。
- 使用 MCUboot + 应用双槽位，保留后续 OTA 升级能力。
- 所有外设引脚、矩阵行列、LED 链、PWM 通道均在设备树和 overlay 中描述，
  应用层不写死 GPIO。

3.2 CAF 模块划分
以 Zephyr Application Event Manager 为事件总线，模块间通过应用事件解耦：
- input/buttons：按键矩阵、编码器输入事件；
- leds：RGB 灯亮度、颜色和渐变动画；
- settings：模式、LED 颜色、亮度、时间等持久化配置；
- power_manager：空闲、休眠、系统关闭策略；
- ble_state：BLE 广播、连接、断开状态；
- usb_state：USB 枚举、挂起、复位状态；
- hid_bridge：将键盘事件转换为 USB HID 或 BLE HID 报告；
- host_link：与上位机之间的私有协议；
- display_ui：LVGL 页面和屏幕状态；
- battery：电量、充放电状态；
- app_mode：USB/BLE 模式切换状态机。

3.3 应用数据流
硬件输入 -> Zephyr input/button 事件 -> 键盘模块去抖并生成按键状态 ->
CAF 事件 -> 当前模式状态机 -> USB HID 或 BLE HID 报告。
LED 效果、屏幕刷新、电源状态和上位机通信分别订阅同一组事件，互不阻塞。

------------------------------------------------
四、功能实现方案
------------------------------------------------

4.1 键盘矩阵扫描与按键输出
1. 使用 6 行 x 4 列矩阵，扫描周期建议 1-5 ms。
2. 列输出扫描脉冲，行输入读取，并用 1N4148W 二极管消除多键同时按下时的
   鬼键问题。
3. 去抖采用时间窗口方式，按下和释放各设置独立去抖时间，建议按下 5-10 ms、
   释放 10-20 ms。
4. 将矩阵位置映射为 HID 键码：
   - 普通键映射到 Keyboard Report；
   - 音量、静音等映射到 Consumer/Media Report。
5. 同一份按键状态同时供 USB HID 和 BLE HID 使用，避免两套映射不一致。
6. 支持全键无冲或 6KRO；当前矩阵规模较小，建议优先验证 N 键同按行为。

4.2 按键 LED 按下点亮、松手渐灭
1. 每颗 WS2812B 独立寻址，通过 Zephyr LED strip 驱动发送 GRB 数据。
2. 按下事件到达后：
   - 从设置中读取该键或全键盘的目标颜色；
   - 在 10-20 ms 内从当前亮度快速升到目标亮度，实现“按下即亮”；
3. 释放事件到达后：
   - 在 150-300 ms 内按固定步进将亮度降到 0，实现渐灭；
   - 渐灭期间再次按下则取消渐灭，重新点亮。
4. 使用一个工作队列定时器统一调度所有活跃 LED，不使用忙等待。
5. 支持全局亮度缩放，颜色、亮度和效果均可由上位机设置。
6. 当无 LED 活动且系统进入低功耗时，关闭 RGB_PWR_EN，切断 RGB_VCC_OUT。

4.3 USB/BLE 模式切换
1. 模式来源：
   - 首选硬件开关 U1 的 MODE 信号；
   - 可选保留键盘组合键作为临时切换。
2. 模式状态机至少包含：USB_ONLY、BLE_ONLY、DUAL。
   本方案按用户要求实现 USB、BLE 两态切换，DUAL 作为可扩展项。
3. USB 模式：
   - 启动 USB HID 设备栈；
   - BLE 可停止广播或仅保留配置服务；
   - 键盘报告只发送到 USB 主机。
4. BLE 模式：
   - 启动 BLE 广播和 HID 服务；
   - USB 不枚举键盘，或仅保留 CDC/厂商通道用于充电和配置；
   - 键盘报告只发送到已连接的 BLE 主机。
5. 切换时必须先发送全键释放，避免切换瞬间主机认为按键卡住。
6. 切换后同步更新屏幕模式图标，并写入 settings 保存默认模式。

4.4 旋钮编码器音量与静音
1. EC11A/EC11B 使用 GPIO 边沿中断或 Zephyr QDEC 外设进行正交解码。
2. 旋转去抖 2-5 ms，并做 4 状态格雷码消抖，避免抖动造成音量跳变。
3. 每识别 1 个有效步进：
   - 顺时针发送 Volume Up；
   - 逆时针发送 Volume Down。
4. 支持旋转加速：连续快速旋转时，按步进倍率放大音量变化量。
5. 按下编码器：
   - 短按切换静音/取消静音；
   - 发送 Consumer Mute 报告；
   - 屏幕同步显示静音图标。
6. 如编码器按键接入键盘矩阵，需要在矩阵映射中将其视为功能键，避免被
   普通键盘报告误发。

4.5 LCD 显示
1. 使用 Zephyr Display API 驱动 SPI 屏，配置 ST7789V/ILI9341 等驱动。
2. 使用 LVGL 绘制界面，页面包含：
   - 当前模式：USB 或 BLE，可加连接状态；
   - 系统时间：HH:MM 或 HH:MM:SS；
   - 屏幕亮度：百分比或图标；
   - 当前电量：百分比、充电中状态。
3. SCREEN_BLK 使用 PWM 调光，亮度范围 1%-100%，默认值可从设置读取。
4. 时间由上位机同步后，使用 RTC 或系统时钟计时；重新上电前未同步时可显示
   占位符或最后保存时间。
5. 屏幕采用部分刷新和低刷新率策略，空闲时关闭背光或进入休眠。

4.6 低功耗与电池电源管理
1. 电源状态划分：
   - Active：按键、BLE/USB 通信、屏幕和 LED 可工作；
   - Idle：无按键、无连接事件，降低 CPU 空闲功耗；
   - Sleep：关闭屏幕背光、关闭 RGB 电源，CPU 进入浅睡；
   - System Off：长时间无活动后进入深度掉电，保留唤醒源。
2. 唤醒源：
   - 任意矩阵行/列 GPIO；
   - EC11 旋转/按下；
   - 电源键 KEY / MANUAL_WAKE；
   - USB VBUS 插入。
3. 进入 Sleep/System Off 前：
   - 先发送全键释放；
   - 关闭 RGB_PWR_EN；
   - 关闭屏幕背光并将 LCD 置于休眠；
   - 停止非必要定时器。
4. 电量检测：
   - 通过 BAT_ADC_EN 使能电池采样，BAT_ADC 读取电池电压；
   - 使用 IP5306 的 I2C 状态寄存器读取充电、充满、放电、低电等状态；
   - 综合开路电压/负载电压和充放电状态估算 SOC。
5. 屏幕电量按百分比显示，低电时告警图标提示。

4.7 与上位机通信、时间同步和 LED 颜色设置
1. 通信通道：
   - BLE：自定义 GATT 服务，包含命令写特征和事件通知特征；
   - USB：HID Vendor 报告（Usage Page 0xFF00）或 CDC-ACM 虚拟串口；
   - 两种通道使用同一套命令帧格式，减少重复逻辑。
2. 命令帧建议包含：帧头、命令号、长度、负载、校验。
3. 命令功能：
   - SET_TIME：同步年、月、日、时、分、秒、星期；
   - GET_STATUS：读取模式、电量、亮度、版本、连接状态；
   - SET_LED_COLOR：设置单键或全键盘 RGB 颜色；
   - SET_LED_BRIGHTNESS：设置全局 LED 亮度；
   - SET_LED_EFFECT：静态、呼吸、关闭等效果；
   - SET_SCREEN_BRIGHTNESS：设置屏幕亮度；
   - SYNC_ACK：时间同步确认或错误码返回。
4. 时间同步后，RTC 按秒递增；支持通过周期同步校正累计误差。
5. 上位机工具可先以串口/HID Vendor 调试，再封装为 Windows/Linux 桌面工具
   或手机 App。

六、实施阶段
------------------------------------------------
阶段 0：硬件点板与工具链验证
  - 确认 3V3、VBAT、VIN/VOUT、VBUS 电压正常；
  - 确认 SWD 可连接、芯片可下载、32.768 kHz 起振；
  - 确认 USB DP/DN 连接和 TYPE-C 方向。

阶段 1：基础驱动与输入
  - GPIO、矩阵扫描、去抖、键码映射；
  - WS2812 灯带驱动；
  - SPI LCD 点亮；
  - EC11 编码器解码；
  - IP5306 I2C 与 BAT_ADC。

阶段 2：HID 与模式切换
  - USB HID 键盘与 Consumer 报告；
  - BLE 广播、连接、HID 服务；
  - USB/BLE 模式状态机与硬件开关。

阶段 3：灯效与上位机协议
  - 按下点亮、松开渐灭；
  - BLE/USB 私有协议；
  - 时间同步、LED 颜色与亮度设置。

阶段 4：低功耗与整机优化
  - 电源状态机、RGB 电源切断、屏幕休眠；
  - 电池电量显示、充电状态；
  - 功耗测量与调优。

阶段 5：UI 完善与系统测试
  - 屏幕 UI 打磨；
  - 完整功能回归、长时间稳定性和兼容性测试。

七、验证方案
------------------------------------------------

7.1 测试环境
- Windows/Linux 主机 1 台，安装 USB HID 抓包工具；
- 蓝牙主机：PC、平板或手机，必要时使用 nRF Sniffer 抓取空中包；
- Nordic Power Profiler Kit II（PPK2）或高精度电流表；
- 万用表、示波器、逻辑分析仪；
- 串口 RTT/J-Link RTT 日志用于观察状态。

7.2 硬件点板验证
- 上电后各电源轨电压、纹波和上电时序符合器件要求；
- 3V3 LDO 输出稳定；
- 32.768 kHz 晶振起振；
- SWD 可正常下载、调试；
- TYPE-C 正反插均能识别，DP/DN 连接正确；
- 电池接口极性、BAT_ADC 分压正确。

7.4 协议与兼容性验证
- 抓取 USB HID Report Descriptor，确认键盘和 Consumer 报告正确；
- 使用蓝牙抓包确认 HID 服务和自定义 GATT 服务广播、发现、读写正常；
- 在不同系统（Windows/macOS/Linux）和不同蓝牙主机上验证输入兼容性；
- 检查报告长度、Boot Protocol、空闲速率等主机兼容项。

7.5 低功耗与电池验证
建议使用 PPK2 分别测量以下场景平均电流：
1. USB 活动模式、屏幕背光关闭；
2. BLE 广播状态；
3. BLE 已连接、100ms 连接间隔、无按键无 LED；
4. Idle/Sleep：屏幕背光关闭、RGB 电源关闭；
5. System Off：长时间无活动；
6. 充电状态和满充状态。

验收目标（初步建议值，最终以实际 PMIC 静态功耗和屏幕规格标定）：
- RGB 电源关闭、屏幕背光关闭的 Sleep 状态，电流应显著低于 Active；
- BLE 空闲连接平均电流目标控制在 1 mA 量级以内；
- System Off 状态达到 nRF52840 + 外设组合的预期微安级；
- 通过波形确认 IP5306 不反复异常唤醒。

7.6 稳定性与回归测试
- 连续按键 1 小时无卡键、无重复、无丢失；
- BLE 连续连接 24 小时无异常断开或死机；
- USB 反复插拔 100 次，枚举和输入稳定；
- 快速旋转编码器 5 分钟，音量变化平滑，无反向抖动；
- 低电、充电、满电状态切换时屏幕和按键功能正常；
- 恢复出厂设置后默认模式、默认颜色和默认亮度正确。

------------------------------------------------
八、风险与关注点
------------------------------------------------
1. IP5306 静态电流可能影响深度休眠目标，需实测后确定关闭策略。
2. WS2812 时序对中断延迟敏感，优先使用硬件 SPI/位带驱动或专用定时器，
   避免高优先级中断造成灯带花屏。
3. USB 与 BLE 同时运行时，供电、时钟和报告去重需重点测试。
4. 屏幕背光和 RGB 灯是主要功耗来源，低功耗策略必须显式关闭。
5. 编码器按键若与矩阵复用，需在矩阵扫描和功能键映射之间做好去重。
6. 上位机协议帧需要版本号与校验，保证 BLE 和 USB 通道行为一致。
