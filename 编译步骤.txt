【2】关键踩坑（为什么不能直接用 west）
----------------------------------------------------------------
  ⚠️ 当前 CodeBuddy 执行会话（PowerShell 临时会话）没有 nCS 环境：
     - 直接 `west` → ModuleNotFoundError: No module named 'west'
     - 原因1：D:/ncs/v3.2.3/zephyr/zephyr-env.cmd 只 set ZEPHYR_BASE
       并 call %userprofile%\zephyrrc.cmd，而该文件【不存在】→ 环境没初始化
     - 原因2：D:/ncs/toolchains/.../Scripts/west.exe 包装器未关联正确 Python
  ✅ 正确做法：用工具链 venv 的 python 直接 `python -m west`，并在同一
     cmd 进程链里设好环境变量（务必用 cmd /c "… && …" 串起来，
     不能分开执行，否则环境变量对后续命令不生效）。
  ⚠️ 命令里【不要加 | tail】（PowerShell 无 tail，会直接报错导致命令不执行）。

【3】编译命令（在 CodeBuddy execute_command 直接运行）
----------------------------------------------------------------
  增量编译（日常，快）：
  cmd /c "set ZEPHYR_BASE=D:\ncs\v3.2.3\zephyr&& set ZEPHYR_SDK_INSTALL_DIR=D:\ncs\toolchains\fd21892d0f\opt\zephyr-sdk&& set ZEPHYR_TOOLCHAIN_VARIANT=zephyr&& set PATH=D:\ncs\toolchains\fd21892d0f\opt\bin;D:\ncs\toolchains\fd21892d0f\opt\bin\Scripts;%PATH%&& cd /d f:\Desktop\32project\kb && D:\ncs\toolchains\fd21892d0f\opt\bin\python.exe -m west build -b kb"

  全量/pristine（新增 .c/.h 或改 Kconfig/prj.conf 后用，确保拾取新文件）：
  把上面末尾的 `-b kb` 改为 `-p always -b kb` 即可。

  产物：build/merged.hex（烧录用）。
