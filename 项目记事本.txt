【3】键盘矩阵（已核实）
----------------------------------------------------------------
  6 行 × 4 列，共 18 个物理位置 = 17 个机械轴 + 1 个 EC11 编码器按键

        | COL0 | COL1 | COL2 | COL3 |
  ROW0  |  —   |  —   |  —   |  ✓   | ← EC11 旋钮按键（经 D20 1N4148W）
  ROW1  |  ✓   |  ✓   |  ✓   |  ✓   | ← 4 个
  ROW2  |  ✓   |  ✓   |  ✓   |  —   | ← 3 个
  ROW3  |  ✓   |  ✓   |  ✓   |  ✓   | ← 4 个
  ROW4  |  ✓   |  ✓   |  ✓   |  —   | ← 3 个
  ROW5  |  ✓   |  ✓   |  —   |  ✓   | ← 3 个（注意第 3 列空缺）

  实际按键数：17 个机械轴（CBB1..CBB17）+ 1 个编码器按键 = 18
  【待确认】用户口径"17 个按键"如已包含编码器，则还有一处空位未说明。

  二极管：每键串 1 只 1N4148W（D1~D19，编码器为 D20）
  方向   ：列 → 行（阳极在开关/列侧，阴极在行侧）【已按原理图符号确认】
  结论   ：扫描必须"列驱动为高、行下拉"，按下时行读到高电平。

【4】键帽布局（原理图内嵌 KLE 图例；机械轴归属【待确认】）
----------------------------------------------------------------
  Esc
  NumLock   /    *    -
  7/Home   8/↑  9/PgUp   +(2U 高)
  4/←      5    6/→
  1/End    2/↓  3/PgDn   Enter(2U 高)
  0/Ins(2U 宽)  ./Del

  结构解读：17 个机械轴 + 1 个旋钮位 = 18 格；大概率 Esc 位就是旋钮。
  【关键】存在 NumLock 双功能层：7/Home、8/↑、9/PgUp、4/←、6/→、1/End、2/↓、
  3/PgDn、0/Ins、./Del 共 10 个双功能键 —— 整机方案 V0.1 里漏了这一层，必须补。

【5】WS2812B 灯带（已核实）
----------------------------------------------------------------
  单条串行链，行优先：
  RGB_DATA → CBB1..CBB4 →【RGB_1】→ CBB5..CBB7 →【RGB_2】→ CBB8..CBB11
           →【RGB_3】→ CBB12..CBB14 →【RGB_4】→ CBB15..CBB17
  RGB_1..RGB_4 只是行间过渡网络名，不是 4 条独立灯带。
  ⚠️ LED 索引（链路顺序）≠ 矩阵 (行,列) 下标，必须建映射表。

【6】屏幕（已核实）
----------------------------------------------------------------
  P3（2.54mm 1x8P 母座）：
    SCREEN_BLK(P1.11) / SCREEN_RES(P1.10) / SCREEN_DC(P0.03) /
    SCREEN_SDA=MOSI(P0.28) / SCREEN_SCL=SCK(P1.13) / SCREEN_CS(P0.02) / 3V3 / GND
  ⚠️ 没有 MISO —— 只写 SPI，DTS 里不能配 miso-gpios。
  ⚠️ SDA 是 MOSI、SCL 是 SCK，命名反直觉，别写错。
  【待确认】驱动 IC 与分辨率（ST7789 / ST7735 ?）

【7】电源（已核实）
----------------------------------------------------------------
  VBUS → R29(2Ω) → IP5306(U2) VIN（充电）
  电池 VBAT → SW4(SK-22D02 拨动开关) → IP5306 BAT
  IP5306 SW → U40(1uH) → SYS_POWER(5V)（C30 220uF + C32/C38 22uF）
  SYS_POWER → U37(TPSPX3819M5-L-3-3 LDO) → 3V3（主控与数字外设）
  电量采样：VBAT → 100k/100k 分压 → Q1 MOS（由 BAT_ADC_EN 控制）→ BAT_ADC(P0.31)，C29 100nF
  灯带电源：SYS_POWER → Q4/Q2(ES3139KW P-MOS) → RGB_VCC_OUT，由 RGB_PWR_EN(P0.13) 控制
  唤醒链  ：MANUAL_WAKE → U41(SN74LVC1G123 单稳态) → IP5305T_WAKEUP → IP5306 KEY
  IP5306 为 I2C 版本，R28/R31 10k 上拉到 3V3

【8】三模开关（推断，【待确认】）
----------------------------------------------------------------
  U1 = SK-13D07-4（6 脚 3 档拨动）
  MODE 只连到 P0.29（AIN5，模拟输入），周边 R5/R18/R19/R20=1k、R16/R17=100k、C9=100nF
  ⇒ 强烈提示是"电阻分压 + ADC 三档判档"（悬空档由 100k 给出 1/2 VCC）
  ⇒ 实现时必须用 ADC 采样 + 阈值 + 回滞，不能简单按数字量读
  【待确认】三档分别代表什么（USB / BLE / 关机？还是 USB / BLE1 / BLE2？）
